# Car Selling App

Car Selling App is a full-stack web application for buying and selling second-hand cars, inspired by DoneDeal but designed to be simpler and more accessible. The platform allows users to register, log in, create and manage car listings, and communicate with other users through a built-in messaging system. The backend is built with Node.js, Express, and MongoDB, while the frontend uses React for a modern, responsive user experience.

**Key Features:**
- User authentication (JWT-based)
- Add, view, update, and delete car listings
- Search and filter listings by brand, model, and price
- Messaging system between buyers and sellers
- Simple, clean, and responsive UI

# İkinci El Araba Satış Uygulaması

Car Selling App, DoneDeal'den esinlenerek geliştirilmiş, ikinci el araba alım-satımı için sade ve erişilebilir bir tam yığın web uygulamasıdır. Kullanıcılar kayıt olabilir, giriş yapabilir, ilan ekleyip yönetebilir ve dahili mesajlaşma sistemiyle diğer kullanıcılarla iletişim kurabilir. Backend Node.js, Express ve MongoDB ile, frontend ise modern ve duyarlı bir deneyim için React ile geliştirilmiştir.

**Temel Özellikler:**
- JWT tabanlı kullanıcı kimlik doğrulama
- Araba ilanı ekleme, görüntüleme, güncelleme ve silme
- Marka, model ve fiyat ile ilan arama/filtreleme
- Alıcı ve satıcılar arasında mesajlaşma
- Basit, temiz ve duyarlı arayüz

## English

### Backend

1. Install dependencies:
   ```bash
   cd backend
   npm install
   ```
2. Edit the `.env` file if needed.

3. Start the server:
   ```bash
   npm start
   ```
4. Run backend tests:
   ```bash
   npm test
   ```

#### Features
- User authentication (JWT)
- Add, list, update, delete car listings
- Messaging system (between buyer and seller)

---

### Frontend

1. Install dependencies:
   ```bash
   cd frontend
   npm install
   ```
2. Start the app:
   ```bash
   npm start
   ```

#### Features
- List car ads
- User login/register
- Car details and messaging

---

#### Notes
- MongoDB is required for backend.
- Frontend and backend run on different ports.
