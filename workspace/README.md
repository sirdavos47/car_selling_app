# Car Selling App - Backend

## Başlangıç

1. Gerekli paketleri yükleyin:
   ```bash
   cd backend
   npm install
   ```
2. .env dosyasını düzenleyin (gerekirse).
3. Sunucuyu başlatın:
   ```bash
   npm start
   ```

## Özellikler
- Kullanıcı kimlik doğrulama (JWT)
- Araba ilanı ekleme, listeleme, güncelleme, silme
- Mesajlaşma sistemi (alıcı/satıcı arasında)

# Car Selling App - Frontend

## Başlangıç

1. Gerekli paketleri yükleyin:
   ```bash
   cd frontend
   npm install
   ```
2. Uygulamayı başlatın:
   ```bash
   npm start
   ```

## Özellikler
- Araba ilanlarını listeleme
- Kullanıcı girişi/kaydolma
- İlan detayları ve mesajlaşma

---

## Notlar
- Backend için MongoDB gereklidir.
- Frontend ve backend ayrı portlarda çalışır.
